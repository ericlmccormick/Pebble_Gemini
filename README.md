# Gemini with Voice — Pebble

Pebble smartwatch Gemini assistant with optional spoken responses.

**Separately maintained companion phone plugins:**
- [Gemini Conversation](https://github.com/ericlmccormick/Pebble-Gemini-plugin) — model selection, API access and text conversation actions
- [Google Cloud TTS](https://github.com/ericlmccormick/Pebble-Google-TTS-plugin) — voice selection, 8 kHz verified audio generation and reusable playback SDK

Both plugins are independently installable. Select sources in the watch app settings; direct API mode remains supported.

For technical details, see [PLUGIN_INTEGRATION.md](PLUGIN_INTEGRATION.md).
