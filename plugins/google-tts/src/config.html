Pebble plugin · Text to speech

Google Cloud TTS

Generate spoken responses for any compatible Pebble app. Only the plugin stores the Google Cloud API key and voice selection.

1

Google Cloud connection

Stored in Pebble secure storage. The key is never returned to calling watch apps.

Google Cloud Text-to-Speech must be enabled on the API key's project. Billing is separate from Gemini or Google AI subscriptions.
2

Voice & pricing

Any app using this plugin receives the selected default voice, unless it requests a different one.

Prices are Google Cloud paid rates in USD per 1 million synthesized characters, after any applicable monthly free allowance. $ = WaveNet, $$ = Neural2, $$$ = Chirp 3 HD.

Google Cloud pricing and free-tier limits.

3

Save & security

Forgets the saved key and temporary WAV chunks. Your watch apps can be reconnected later.
